# 🧠 Знание — сила

Викторина-бот для мессенджера MAX по школьным предметам. Ученики отвечают на вопросы, набирают очки, собирают серии верных ответов и попадают в общий рейтинг. Учителя могут создавать собственные опросы и смотреть статистику прохождения.

## Возможности

**Для учеников**

- Игра по предметам или в режиме «🎲 Микс» (10 вопросов, 3–4 варианта ответа).
- 10 очков за верный ответ + бонус за серию: +2 очка за каждый ответ в серии (до +10).
- Подсказка «50/50» — один раз за игру.
- Звания по итогам игры: 🌱 Начинающий, 📘 Хорошист, 🥇 Отличник, 🎓 Профессор.
- Общий рейтинг и личная статистика.
- Прохождение опросов от учителей.

**Для учителей**

- Создание опросов прямо в чате (вопрос + 3–4 варианта, верный отмечается `+`).
- Статистика по опросу: число прохождений, средний результат, топ учеников, самые сложные вопросы.
- Удаление своих опросов.

## Создайте виртуальное окружение

1. Запустите Visual Studio Code и через меню «Файл» / «Открыть директорию» откройте папку проекта.
2. Запустите терминал в VS Code, убедитесь, что вы работаете из корневой директории проекта (если вы работаете под Windows, убедитесь, что в терминале запущен Git Bash, а не PowerShell или что-нибудь ещё), и выполните команду:

- Linux/macOS

```bash
python3 -m venv venv
```

- Windows

```bash
python -m venv venv
```

В директории проекта будет развёрнуто виртуальное окружение и появится папка `venv`, в которой будут храниться все зависимости проекта, а структура файлов станет такой:

```
znanie-sila/
└─ bot/
├─ venv/ Директория виртуального окружения
├─ data/
│ └─ scores.db База данных SQLite (создаётся автоматически)
├─ bot.py Основной код бота
├─ questions.py Банк вопросов по предметам
├─ .env Токен бота и ID администраторов (скрытый)
├─ .gitignore Список файлов и папок, скрытых от отслеживания Git
├─ README.md Описание проекта
└─ requirements.txt Список зависимостей проекта
```

## Активация виртуального окружения

В терминале перейдите в корневую директорию проекта и выполните команду:

- Linux/macOS

```bash
source venv/bin/activate
```

- Windows (Git Bash)

```bash
source venv/Scripts/activate
```

- Windows (PowerShell)

```powershell
venv\Scripts\Activate.ps1
```

Теперь все команды в терминале будут предваряться строкой `(venv)`.

> 💡 Все дальнейшие команды в терминале надо выполнять с активированным виртуальным окружением.

Обновите pip:

```bash
python -m pip install --upgrade pip
```

## Установка зависимостей из файла requirements.txt

Находясь в корневой папке проекта, выполните команду:

```bash
pip install -r requirements.txt
```

Содержимое `requirements.txt`:

```
maxapi
python-dotenv
```

## Настройка переменных окружения

Создайте в корне проекта файл `.env`:

```env
MAX_BOT_TOKEN=f9LHodD0cOIAErl-nyBHGtvM7Vx72pH7GrzP9ZF3JccB14ZY0PPgJgxTQ-Jj7o-Z5f3iofeD15pI9bVJ-DKF
ADMIN_IDS=12345678,87654321
DB_PATH=data/scores.db
```

| Переменная | Описание |
|-----------------|-------------------------------------------------------------------|
| `MAX_BOT_TOKEN` | Токен бота, полученный в MAX |
| `ADMIN_IDS` | ID учителей через запятую — им открывается «Кабинет учителя» |
| `DB_PATH` | Путь к файлу базы данных (необязательно, по умолчанию `data/scores.db`) |

> ⚠️ Никогда не коммитьте `.env` и не храните токен в коде. Добавьте `.env` и `data/` в `.gitignore`.

Свой ID можно узнать, отправив боту команду `/id`.

## Запуск проекта

В директории с файлом `bot.py` выполните команду:

```bash
python bot.py
```

В консоли появится список `ADMIN_IDS`, а бот начнёт принимать сообщения (long polling).

## Команды бота

| Команда | Действие |
|----------|-----------------------------|
| `/start` | Главное меню |
| `/play` | Выбор темы и начало игры |
| `/top` | Рейтинг игроков |
| `/rules` | Правила игры |
| `/id` | Показать свой ID |

## Как создать опрос (для учителя)

1. Откройте «🧑‍🏫 Кабинет учителя» → «➕ Создать опрос».
2. Введите название опроса.
3. Отправьте текст вопроса.
4. Отправьте варианты ответа — каждый с новой строки (3–4 штуки), верный отметьте плюсом в конце:

```
Москва +
Париж
Берлин
Рим
```

5. Нажмите «➕ Ещё вопрос» или «✅ Завершить». Готовый опрос сразу доступен ученикам.

## Как добавить вопросы в игру

Вопросы хранятся в файле `questions.py` в виде словаря `предмет → список вопросов`. Каждый вопрос — кортеж:

```python
(текст вопроса, "верный ответ", ["неверный 1", "неверный 2", "неверный 3"])
```
